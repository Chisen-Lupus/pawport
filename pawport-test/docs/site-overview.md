# PawPort 网站详细说明

PawPort 是一个用于记录兽展足迹、查看同好参展历史与住宿分布的地图网站。当前域名规划为 `pawport.me`，服务器 IP 为 `45.32.59.92`，本地开发使用 macOS + SQLite，生产环境使用宝塔面板 + Nginx + Node.js 后端 + MySQL。

本文是功能与架构说明，部署和日常运维命令见 [server-ops.md](./server-ops.md)。

## 目标

PawPort 主要解决两个问题：

- 用户可以标记自己去过或计划参加的兽展，并形成个人参展历史。
- 用户可以了解其他公开用户去过哪些展，以及当前/未来展会中大家可能住在哪里。

设计上保留较强扩展性：

- 用户、兽展、参展记录、酒店都有可扩展字段或可继续扩展的数据结构。
- 登录系统先支持本地账号，后续预留 Google、手机号、微信、QQ 登录与合并账户。
- 菜单中预留活跃用户、兽聚统计、社交功能、酒店协作等未来入口。

## 主要用户角色

### 未登录访客

未登录用户可以：

- 查看首页地图。
- 查看公开兽展节点。
- 查看公开用户的头像、参展历史和轨迹。
- 查看展会窗口中的公开参展者列表。
- 切换中英文、亮暗模式、测试数据、地图视图和筛选条件。

### 普通登录用户

普通用户可以：

- 注册、登录、退出。
- 修改个人资料、头像、主题色、简介。
- 修改密码。
- 设置是否公开参展记录。
- 设置是否在首页展示轨迹。
- 设置是否展示住宿信息。
- 标记或取消标记参展。
- 给参展记录添加寄语、评分和酒店。
- 提交新兽展。
- 查看和编辑“我提交的展”。
- 对被拒绝的提交重新提交审核。
- 导出当前用户资料，便于测试阶段恢复。

### 管理员

管理员可以：

- 进入 `/admin` 管理员后台。
- 查看待审核、已通过、已拒绝或全部用户提交展会。
- 搜索审核记录。
- 修改展会基础信息、系列信息、地址、经纬度、官网/信息来源等字段。
- 通过或拒绝用户提交的展会。
- 看到提交者信息。

测试数据中包含管理员账号：

```text
admin@pawport.me / test123456
```

## 首页地图

首页是网站的核心界面。它不是营销页，而是直接显示可操作的世界地图。

### 地图底图

当前前端使用 Leaflet：

- 支持缩放和平移。
- 支持亮色和暗色地图。
- 支持无标签底图加自定义国家/城市标签。
- 地图配置在 `config/site.config.js` 中。
- 默认视角偏向中国和亚洲区域，方便本地测试。

地图标签中包含主要国家和主要城市，例如中国、美国、日本、韩国、北京、上海、广州、深圳、成都、香港、台北、东京、首尔等。

### 兽展节点

兽展在地图上以圆角矩形图标显示，用来和用户圆形头像区分。

节点行为：

- 已结束展会使用较弱的视觉样式。
- 未来展会使用主题色。
- 当前进行中的展会会高亮，并带扩散动效。
- 有海报或头像的展会会在图标中使用图片填充显示。
- 同一地点或近距离展会会并排成团放置，减少重叠。
- 合并同系列时，同一展会系列默认只显示一个代表节点。

当前展会的判定窗口为：

- 展会开始前 1 天。
- 展会结束后 1 天。

### 当前展会参展气泡

当前进行中的展会可以显示一个参展者头像气泡：

- 头像 5 个一行。
- 超过 19 个后，最后一个显示 `+xx`。
- 气泡锚点在展会图标上方，避免遮挡图标。
- 顶部“正在进行”按钮可以作为当前展会名单显示开关。

### 地图筛选

首页提供多种筛选：

- 地区筛选：
  - 全部地区
  - 中国大陆
  - 亚洲
  - 美国
- 日期范围筛选：
  - 默认显示当前日期前后约 1 个月。
  - 可以一键前后移动一个月。
  - 可以重置。
  - 可以切换为全部日期。
- 测试数据开关：
  - 默认打开。
  - 可在左上角菜单切换。
- 登录后可开启“只看我的”。
- 可切换“近期兽展视图”和“全部轨迹视图”。

### 轨迹显示

用户轨迹表示公开用户按时间顺序参加展会的路径。

轨迹规则：

- 只展示公开参展记录且允许首页展示轨迹的用户。
- 按展会开始日期排序，不按添加顺序排序。
- 使用逆时针弯曲弧线连接参展节点。
- 轨迹线带方向箭头。
- 多个用户共享同一段路径时，线宽会变粗。
- 鼠标悬浮时，在鼠标位置显示该路径人数。
- 轨迹图层位于兽展图标下方，避免遮挡节点。

轨迹开关：

- 显示/隐藏轨迹。
- 隐藏无轨迹节点。
- 显示所有人轨迹。
- 合并同系列展会。
- 只看我的轨迹。

当“隐藏无轨迹节点”和“合并同系列”同时开启时，代表节点会优先选择同系列中包含轨迹的最近一届。

### 窗口系统

点击地图上的展会或用户，会打开可拖拽窗口。

窗口特性：

- 窗口可自由拖动。
- 窗口可关闭。
- 有一键清除全部窗口按钮。
- 打开/关闭/拖拽有动画。
- 点击展会图标时，图标会以放大的方式过渡到窗口。
- 窗口栈可以同时保留多个信息窗口。

### 展会窗口

展会窗口展示：

- 名称。
- 日期。
- 会场/地址。
- 城市和国家。
- 展会头像或海报。
- 主题色。
- 信息来源链接。
- 同一系列的其他届次链接。
- 参展者头像列表。
- 酒店分布统计。
- 登录用户的标记参展/取消参展按钮。

“官方网站”字段在界面中显示为“信息来源”，以兼容来自不同数据源的链接。

同一系列展会链接会在原窗口内切换内容，而不是新开窗口。

### 用户窗口

用户窗口展示：

- 用户头像。
- 显示名。
- 简介。
- 公开参展历史。
- 允许公开的住宿信息。
- 对用户本人可见的待审核/已拒绝状态提示。

## 参展记录

用户可以从两处添加参展：

- 在地图上点开展会窗口，点击标记参展。
- 在个人资料的“参展历史”区域搜索展会并添加。

参展记录支持：

- 寄语/评价。
- 评分。
- 多个住宿酒店。
- 酒店入住/退房日期。
- 酒店备注。
- 扩展字段。

标记参展和取消参展是同一个按钮的两种状态。

参展历史默认按展会时间倒序显示。

## 酒店功能

酒店被设计成独立数据库，而不是简单文本字段。

酒店数据包括：

- 名称。
- 地址。
- 城市。
- 国家。
- 经纬度。
- 官网。
- 电话。
- 扩展字段。

参展历史中可以编辑酒店：

- 搜索已有酒店。
- 提交新酒店。
- 地址是可选字段。
- 可以使用会场/官方酒店名称作为填写参考。
- 可以为同一参展记录添加多个酒店。

展会窗口中，如果有参展者填写酒店，会显示住宿分布饼图。

## 用户提交兽展

普通用户可以提交新兽展。提交字段包括：

- 名称。
- 开始日期。
- 结束日期。
- 当地语言名。
- 系列标识。
- 届次。
- 会场。
- 地址。
- 城市。
- 经纬度。
- 主题。
- 主题色。
- 信息来源链接。
- 展会头像。

提交提示会说明：

> 只有填写了经纬度，并且经过管理员批准的兽展，才会显示在地图轨迹图上。

提交逻辑：

- 普通用户提交后状态为 `pending`。
- 管理员提交后状态为 `approved`。
- 每条用户提交的展会会记录 `submitted_by`，保存提交者用户 ID。

## 我提交的展

个人资料中有“我提交的展”区域。

用户可以：

- 查看自己提交过的展会。
- 看到每条提交的状态：
  - 待审核
  - 已通过
  - 已拒绝
- 展开编辑提交内容。
- 保存字段修改。
- 对已拒绝记录点击“重新提交”，把状态改回 `pending` 等管理员重新审核。

普通用户不能自己把展会改成 `approved`，只有管理员可以通过。

## 审核与可见性

兽展审核状态：

- `pending`：待审核。
- `approved`：已通过。
- `rejected`：已拒绝。

可见性规则：

- 首页地图只显示 `approved` 展会。
- 公开用户页只显示 `approved` 展会。
- 首页轨迹只使用 `approved` 展会。
- 普通参展历史默认只显示 `approved` 展会。
- 用户本人可以看到自己参展历史中的 `pending` 和 `rejected` 记录，并显示状态提示。
- 被拒绝记录不会出现在公开页面和首页轨迹中。

## 数据来源

PawPort 当前有三类展会数据来源。

### 用户提交

用户手动提交展会，进入审核流程。

### furrycons.cn

用于同步大中华地区数据。

配置项包括：

- `baseUrl`
- `syncFrom`
- `syncPastMonths`
- `syncFutureMonths`
- `pageSize`
- `maxPages`
- `syncInterval`

同步策略：

- 可从 2015 年开始同步。
- 可保留历史数据。
- 默认定期同步。
- 如果没有精确坐标，可记录为城市级位置精度。

### furrycons.com

用于补充国际历史展会数据。

配置项包括：

- 从 1989 年开始。
- 启动时同步一次。
- 每月同步一次。
- 支持详情页坐标补全。
- 支持详情回填限速。
- 受到限流时可停止详情抓取。

为避免和 furrycons.cn 冲突，furrycons.com 同步会忽略中国大陆、港澳台记录。

### 东亚非大中华地区

日本、韩国等东亚非大中华地区兽展目前仍在寻找合适 API 或数据库来源。

当前处理方式：

- 用户可以手动添加。
- 后续如果接入合适数据源，再考虑手动合并已有记录。

## 文件上传

当前支持：

- 用户头像上传。
- 展会头像上传。

上传文件保存在后端：

```text
pawport-test/backend/uploads
```

生产环境迁移时，数据库迁移不会自动迁移图片文件，需要单独同步 `backend/uploads`。

Nginx 需要让 `/uploads/` 走后端反代，并避免被图片静态缓存正则抢走：

```nginx
location ^~ /uploads/ {
    proxy_pass http://127.0.0.1:3001;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
}
```

## 本地开发

本地开发推荐：

```bash
cd pawport-test/backend
npm install
npm run db:reset
npm run dev
```

另开终端：

```bash
cd pawport-test/frontend
npm install
npm run dev
```

访问：

```text
http://localhost:5173
```

## 生产部署概要

生产部署使用：

- 宝塔面板创建网站。
- Nginx 服务前端静态文件。
- Nginx 反代 `/api` 和 `/uploads` 到后端。
- PM2 管理 Node.js 后端。
- MySQL 存储生产数据。

前端正式构建输出目录：

```text
pawport-test/frontend/dist
```

Nginx `root` 应该指向该目录，而不是项目根目录或 `www` 占位目录。

## 当前限制和注意事项

- `www/index.html` 是旧占位页，不是正式前端。
- OAuth、短信登录、微信/QQ 登录尚未启用。
- 社交功能、活跃用户列表、兽聚统计、酒店协作仍是预留入口。
- 日本、韩国等东亚非大中华地区仍缺少稳定自动数据源。
- 生产迁移数据库时不会自动迁移上传文件。
- 用户可以编辑自己提交的展会，但不能自行批准。
- 被拒绝展会需要重新提交审核后由管理员处理。
